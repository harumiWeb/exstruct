# ADR-0011 / ADR-0012 implementation and design review evidence

## Scope and structural prerequisite

Independent Orca Codex review compared integrated `10f53cf` with base `5bcb0e4`
in two read-only passes. It reviewed direct cell/BIFF semantics, sparse storage,
session ownership/fallback/concurrency tests, lazy imports and rich OOXML,
optional SciPy metadata/CI, ADR-0011/0012 and related ADR-0002/0003/0010, public
`docs/api.md`, and the linked extraction specs/src/tests.

ADR lint found no unresolved high/medium structural findings: both drafts are
`proposed`, have required sections, concrete Tests/Code/Related specs, balanced
consequences and consistent supersede sections. Design review followed lint.

## Initial findings and resolution

- Medium / evidence-risk / policy-drift: local backend imports bypassed explicit
  legacy `pipeline.ComBackend`, `ComRichBackend` and `LibreOfficeRichBackend`
  overrides. This contradicted ADR-0011's live-override compatibility claim.
  The initial reviewer verdict was `revise`; no new policy was needed.
- Low / index consistency: ADR-0012 listed `benchmark/issue148-results.md` as
  Related specs but its derived YAML entry omitted that path.

Commit `4952ed9` fixes both. `_backend_type` honors explicitly bound pipeline
aliases and otherwise resolves the concrete backend lazily. The regression
subprocess checks all four affected COM steps and both rich-backend selections
without importing concrete COM/LibreOffice modules. ADR-0012's index reference
now matches the source.

## Independent focused verification

A separate read-only verification task targeted exact commit
`4952ed9ee21a622d45dceba3d5d3ffaf70cb4219`, limited to closing those findings.
It confirmed explicit overrides, the default lazy/live resolution of all three
aliases, and a fresh-process real light extraction that returned 33 shapes
without loading the tested COM/render roots. It confirmed the source/index
benchmark reference and current lint prerequisites.

- adr-reviewer verdict for the resolved claims: **ready**.
- adr-reconciler findings for those claims: **none**.
- Open questions in the focused scope: **none**.
- ADR statuses remain `proposed`; a ready review does not change their status.

## Validation boundaries

The independent review did not run full suites, actual COM/LibreOffice, timing,
wheel installs or remote CI. The coordinator separately verified the final
non-COM suite (1017 passed, coverage 83.09%), actual COM (8 passed), forced
LibreOffice (1 passed), PDF/PNG rendering (3 passed), installed base/fast wheels,
and exact output parity for the twelve measured input/mode combinations.
See `benchmark/issues145-148-results.md` for measurements and their limits.
Remote CI is distinct from this local evidence. This focused confirmation is
not a new broad review of unrelated code or a statistical performance approval.
