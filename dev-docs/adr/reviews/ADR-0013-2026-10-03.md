## Structural review

`adr-linter`: no findings. ADR-0013 has a valid `proposed` status, required
sections, concrete tests/code/spec evidence, balanced consequences and explicit
supersede fields. The later clarification about compatibility's own fallback
reason preserves those requirements and matches the implementation.

`adr-indexer`: README, index.yaml and decision-map.md were synchronized. The
13 ADR IDs, paths, status/domain entries and supersede relationships are
consistent. ADR-0013 remains proposed.

## Design review

`adr-reviewer` verdict: `ready`. Findings: none. Open questions: none.

Scope: ADR-0013 and the amended ADR-0011/0012; public API/CLI docs and English/
Japanese README; `excel-extraction.md`, `ooxml-core-extraction.md`,
`extraction-performance.md`; `pipeline.py`, `ooxml_session.py`, `cells.py`,

`adr-reconciler`: no findings; recommended action `no-action`. The issue's
requested backend priority, whole-result compatibility restart, preserved
per-sheet drawing behavior and direct-light Python clustering exception agree
across ADR, specs, source and tests. The reviewer read the evidence and did not
independently rerun the full suite or performance measurements.

Residual risks: fallback workbooks can require two reader attempts; supported
rich artifacts remain best-effort. Windows benchmark observations do not imply
universal latency or memory guarantees. `ready` is a review verdict, not merge
approval or an accepted ADR status.

## Implementation review follow-up

The separate code reviewer confirmed two P2 parity defects in the initial
implementation: unquoted coordinate-like sheet names were shifted as cell
references in shared formulas, and uppercase elapsed-time formats were treated
as dates. Both were corrected before completion:

- Unquoted sheet qualifiers, non-ASCII shared names and references crossing
  worksheet bounds request whole compatibility extraction. Ordinary A1,
  quoted sheet names and string literals retain direct translation support.
- Elapsed-time format matching is case-insensitive; the numeric cached value
  and merged anchor retain the established duration representation.

Evidence: `tests/core/test_light_ooxml_pipeline.py` compares actual shared
formula followers and uppercase duration output with the compatibility
pipeline; `tests/core/test_ooxml_scalars.py` covers capability signaling.
